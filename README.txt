FreeToolHub complete starter project

Open this folder in VS Code. Run index.html with Live Server. Keep all HTML files in the same folder.

All 18 homepage cards have matching pages. Some tools are functional browser-side utilities; PDF libraries and QR/currency features require internet. PDF Security is an information/download page, not encryption. PDF Editor is a simple first-page text annotation tool. BMI page includes an under-18 warning.
